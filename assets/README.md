# Assets

Поместите сюда следующие файлы:

- `icon.png` - иконка приложения (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `splash.png` - splash screen (1284x2778)
- `favicon.png` - favicon для web (48x48)

Вы можете использовать временные изображения из интернета или создать свои.

Для быстрого старта можно использовать любые PNG изображения подходящего размера.
